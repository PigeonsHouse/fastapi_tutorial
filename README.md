# FastAPI をおしえるの会 リポジトリ

## 起動方法

1. (初回のみ) バージョン管理ツール `uv` を導入する (https://docs.astral.sh/uv/#installation)
2. (初回のみ) `uv sync` で python に必要なライブラリをダウンロード
3. `uv run uvicorn main:app --reload` で起動
4. `http://localhost:8000` にアクセス

## やること

- 起動後に SNS でログインができるのを確認してもらう
- その処理がバックエンドでどう動いてるかソースを見てもらう
- 投稿機能のエンドポイントがごっそりないのでその記述を追加してもらう
  - `cruds.py`に DB から Content を全部持ってきて返す関数を定義してもらう
  - `routers.py`に`cruds.py`で作った関数を呼んで返り値を返してもらう
  - `cruds.py`に引数から投稿データを作成し出来たデータを返す関数を定義してもらう
  - `routers.py`に`cruds.py`で作った関数を呼んで返り値を返してもらう
- docs で適宜試しつつ、完成したら`home.html`(フロント)でも動いてるか見てもらう
- 動いたら完成！！やった！嬉しい！
- 鳩屋敷に余裕があれば、エンドポイントの参照先を書き換えると皆で書き込みできるバックエンドにつながって、皆で SNS して遊んで終わりってやりたい。

## ファイル構成

```py
fastapi_tutorial/
  │
  │ # HTMLやCSS、JSのファイルがおいてある。中身はまじまじと見ないで…
  ├ frontend/
  │   │
  │   │ # CSSファイルがおいてある。各HTMLのコメントを解除するとスタイルが適用される。
  │   ├ css/
  │   │
  │   │ # JSファイルがおいてある。FastAPIのエンドポイントを叩く処理が書いてある。
  │   ├ js/
  │   │
  │   │ # サインアップ、サインインのリンクとバックエンドのdocsのリンクがあるページ
  │   ├ index.html
  │   │
  │   │ # サインアップのフォームのページ
  │   ├ signup.html
  │   │
  │   │ # サインインのフォームのページ
  │   ├ signin.html
  │   │
  │   │ # SNSのホーム画面
  │   └ home.html
  │
  │ # FastAPIのメインのファイル。起動コマンドのmainはこのファイル名を指している
  ├ main.py
  │
  │ # DBとの接続や、テーブルの定義などが書かれているファイル。
  ├ db.py
  │
  │ # DB操作を行う関数の定義がされているファイル。
  ├ cruds.py
  │
  │ # エンドポイントの処理を定義しているファイル。
  ├ routers.py
  │
  │ # FastAPIで扱うデータの型を定義しているファイル。
  ├ schemas.py
  │
  │ # その他細々とした関数が定義されているファイル。
  ├ utils.py
  │
  │ # DB本体。当然ファイルを消したらDBがまるっと消える。テスト用データが入っている。
  ├ db.sqlite3
  │
  │ # このリポジトリで使っているライブラリの一覧が書かれているファイル。
  ├ pyproject.toml
  │
  │ # バージョン管理ツール uv のライブラリのロックファイル。syncする時、これがあるので、ライブラリだけでなくそのバージョンも統一される。
  ├ uv.lock
  │
  │ # 名前の通り、Pythonのバージョンを揃えるために書いてあるファイル。uvがこれを見てPythonのバージョンを合わせてくれる。
  ├ .python-version
  │
  │ # プログラム内で使う環境変数を定義しているファイル。実際に使うときは、.env.sampleをコピーして.envを作成し、各自の値を入れてもらう。
  │ # 一応プログラム内でも.envがない場合のデフォルト値は設定してある。
  ├ .env.sample
  │
  │ # このリポジトリで使わないファイルをgitの管理対象から外すためのファイル。.envやuv関連のフォルダなど。
  ├ .gitignore
  │
  │ # これがこのREADMEファイル
  └ README.md
```
